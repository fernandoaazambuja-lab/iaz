iAz

Câmbio, grãos 2027, energia e troca de fertilizante em sacas de soja, atualizado a cada ~5 min.

Só quer usar o app? Basta o passo 1. Quer os números sempre à vista na tela inicial (widget)? Siga os 5 passos.

1Ícone na tela inicial

  1. No Safari, toque no botão abaixo para abrir o iAz.
  2. Na página que abrir, toque em Compartilhar (quadrado com seta para cima).
  3. Toque em Adicionar à Tela de Início → Adicionar. Depois volte aqui.
Abrir o iAz

2Baixe o Scriptable

App gratuito que mostra o widget com os números na tela inicial.

Abrir na App Store

3Copie o código

// iAz — carrega o widget publicado (atualiza sozinho quando o código mudar)
const codigo = await new Request("https://fernandoaazambuja-lab.github.io/iaz/iaz-widget.js?t=" + Date.now()).loadString()
await eval("(async () => {" + codigo + "\n})()")

4Cole no Scriptable

  1. Abra o Scriptable e toque no + (canto de cima).
  2. Toque e segure na área em branco → Colar.
  3. Toque no título no alto e renomeie para iAz.
  4. Toque no ▶: deve aparecer o quadro verde com os números. Depois, Done.

5Widget na tela inicial

  1. Toque e segure num espaço vazio da tela inicial → Editar → Adicionar Widget.
  2. Procure Scriptable, escolha médio (6 números) ou grande (todos) → Adicionar Widget.
  3. Toque no widget cinza → Script: iAz → When Interacting: Open URL. Toque fora para fechar.

O iOS atualiza o widget sozinho, em geral a cada 5 a 15 minutos. A hora no canto mostra de quando é o dado.
